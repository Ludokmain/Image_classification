# Homework 2 – Image Classification with Transfer Learning

Computer Vision, Fall 2026 – Ludovica Rinaldi

This repository compares three transfer-learning strategies for classifying the 37 breeds of the Oxford-IIIT Pet dataset with a pre-trained MobileNetV3-Small (`MobileNet_V3_Small_Weights.DEFAULT`, ImageNet-1K). The strategies are full fine-tuning, classifier-head training, and frozen features fed to a scikit-learn classifier (Logistic Regression and Linear SVM).

## Environment

- Python 3.13.5
- PyTorch 2.15.0
- TorchVision 0.29.2
- scikit-learn 1.9.1

All other dependencies are pinned in `requirements.txt`. The results were produced on Apple Silicon (MPS). The script uses `cuda`, `mps` or `cpu`, in that order, depending on what is available.

```bash
git clone https://github.com/Ludokmain/Image_classification.git
cd <repository-name>
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Dataset

The dataset is the Oxford-IIIT Pet Dataset ([https://www.robots.ox.ac.uk/~vgg/data/pets/](https://www.robots.ox.ac.uk/~vgg/data/pets/)) by Parkhi et al. (CVPR 2012). It is licensed under CC BY-SA 4.0.

The dataset is not included in this repository. The script downloads it automatically to `./data/` through `torchvision.datasets.OxfordIIITPet`.

- The official `trainval` partition is split 80/20 into train and validation sets, stratified by breed (seed 42). The indices are saved in `splits.npz`.
- The official `test` partition is used only for the final evaluation.
- The number of images per breed in each split is listed in `class_counts.csv`.

## Running the experiments

A single command runs all three approaches. It covers data loading, splitting, training, feature extraction and evaluation, and it generates every figure and table.

```bash
python project.py
```

The run takes about 15–20 minutes on MPS. All outputs are written to the repository root and overwrite the files provided.

## Outputs
All the outputs are provided in this repository without the need to run the project.
| File | Content |
|------|---------|
| `results.json` | Versions, seeds, hyperparameters, selected checkpoint/C, training curves, all metrics |

| `confusion_matrix_*.png` | Test confusion matrices |

`features.npz` (extracted features) is also generated by the script. It is not committed because of its size.

## Selected models and hyperparameters

| Approach | Setup | Selected |
|----------|-------|----------|
| Full fine-tuning | AdamW, lr 1e-4, weight decay 0.01, batch 32, 10 epochs, CrossEntropyLoss | epoch 10 |
| Classifier-head training | same as above; only `classifier[0]` and `classifier[3]` are trainable | epoch 9 |
| Features + Logistic Regression | StandardScaler + LogisticRegression, C ∈ {0.001, 0.01, 0.1, 1} | C = 0.001 |
| Features + Linear SVM | StandardScaler + LinearSVC, C ∈ {0.001, 0.01, 0.1, 1} | C = 0.001 |

Checkpoints and values of C are selected on validation accuracy only. The test set is used once, for the final evaluation.

## Reproducibility

- The seed is `42` for Python, NumPy, PyTorch, the DataLoader generator and scikit-learn (`random_state`).
- The following determinism settings are enabled: `cudnn.deterministic = True`, `cudnn.benchmark = False`, `torch.use_deterministic_algorithms(True, warn_only=True)`, `CUBLAS_WORKSPACE_CONFIG=:4096:8`.
- Some variation remains. With `warn_only=True`, operations that have no deterministic implementation still run, and MPS does not guarantee bit-exact results. Results and timings can therefore differ slightly on other hardware or with other library versions.
